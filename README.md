# engageLively/.github

Organization-wide defaults for engageLively repositories.

- [CONTRIBUTING.md](CONTRIBUTING.md): the rules that apply to every repository. GitHub shows this file on any engageLively repository that doesn't have its own.
- [style-guide/](style-guide/): the engineering style guide, with shared principles for code and testing and one page per language.

The guide is built on John Ousterhout's [*Tcl/Tk Engineering Manual*](https://www.tcl-lang.org/doc/engManual.pdf).
